How to install an extension from the zip

Until an extension is on the Chrome Web Store or Edge Add-ons, you install it yourself using "Load unpacked". It takes about two minutes and you only do it once per extension.

  1. Download the zipOpen the extension and click Download zip. It saves to your Downloads folder.
  2. Extract the zipRight-click the zip file and choose Extract All (Windows) or double-click it (Mac). Move the extracted folder somewhere safe, like Documents\Eegai. Do not delete this folder later, or the extension stops working.
  3. Open the extensions pageType chrome://extensions in the address bar and press Enter.
  4. Turn on Developer modeSwitch on Developer mode at the top-right of the page.
  5. Load the folderClick Load unpacked and select the extracted folder, the one that contains manifest.json. The extension appears in the list.
  6. Pin itClick the puzzle-piece icon next to the address bar and click the pin next to the Eegai extension, so its icon is always visible.

Updating to a new version

Download the new zip, extract it and replace the files in your existing folder. Then open the extensions page and click the reload (↻) icon on the extension card. Your trial and licence stay the same.

If you see "Manifest file is missing"

You selected the wrong folder. Open the extracted folder until you see manifest.json directly inside it, and select that folder.
