Put extension zip files in this folder.

Current names the website expects (see "download:" in data/extensions.js):
  eegai-copy-paste.zip
  eegai-awb-tracking.zip
  eegai-gmail-summary.zip
  eegai-webcall-link.zip

Rules:
- Names are case-sensitive on the web. Use lowercase with dashes.
- The zip must contain the extension files (manifest.json etc.) only.
  Never include licence-server code, Apps Script files, passwords or store images.
- Keep each zip under 25 MB (GitHub web upload limit).
